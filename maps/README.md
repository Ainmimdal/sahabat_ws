# Sahabat maps

Maps created from the Sahabat mapping panel are saved here by default.

Each named map can contain:

- `<name>.yaml` and `<name>.pgm`: the finished occupancy map used by Nav2.
- `<name>.posegraph` and `<name>.data`: an editable SLAM session that can be
  reopened by advanced mapping tools.

Use meaningful names such as `gallery_ground_floor` or `exhibit_layout_v2`.
The mapping panel asks before replacing existing files.
